# AHB-APB-Bridge

## Overview
Designed and implemented an AMBA AHB-to-APB bridge in Verilog for protocol conversion between AHB and APB buses.

## Features
- AHB to APB protocol conversion
- Read and write transaction support
- FSM-based control logic
- Simulated and verified in Vivado

## Tools Used
- Verilog
- Xilinx Vivado

## Project Structure

AHB-APB-Bridge/
├── rtl/
├── tb/
└── README.md

## Results
Successfully simulated AHB read and write operations and verified protocol behavior using waveform analysis.
